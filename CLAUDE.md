# SmartLend — instructions for AI sessions

Final-year research project + publication candidate. **Read
`docs/PROJECT-OVERVIEW.md` first** — it is the master document (system diagram,
findings, file map, env). `docs/STATUS.md` is the current state.

## Hard rules

- **`backend/` never imports `research/`, and the API never trains.** Grep-tests enforce no training constructs in the capture layer — do not "fix" those tests.
- **Do not wire retraining.** `research/relearning/gate.py` says DO NOT OPEN THE LOOP and its refusal is the design (runaway feedback loops / selective labels). Never disable the 3% exploration arm.
- **Never tune a threshold on the test split.** Copy the tune/test split discipline of `research/deferral/evaluate.py` (seed 20260831) for any new study.
- **Artifacts are regenerated by committed scripts, never hand-edited.** If you run an experiment, commit the script and write a `reports/*.json` — uncommitted one-off runs caused the TabPFN row-alignment failure.
- **Every number quoted in docs must trace to a `reports/*.json`** with its sample stated. Direction traps: `y_true==1` = GOOD in serving/`prediction_outputs.csv`; 1 = DEFAULT in `complementarity.json` and training labels; SHAP is P(default) log-odds.
- **Changing blend α, deferral mode, gates or confidence formula → bump `ENGINE_VERSION`** in `decision_engine.py` (keeps capture rows separable).
- **AI components stay advisory.** The agent briefing and remote-TabPFN second opinion must never write to `final_decision` (governance + non-commercial licences).
- **Secrets only via `backend/app/config.py`** reading root `.env`. Never a stale constant for anything that can change (`/health` once served synthetic-era numbers for weeks).
- Optional services (TabPFN endpoint, agent, voice) must degrade to a calm 503 with setup instructions, never a 500.

## Commands

```bash
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000   # backend
cd frontend && npm run dev                                             # frontend (proxies /api)
python -m pytest backend/tests research/tests -q                       # full suite
cd frontend && npx tsc --noEmit                                        # typecheck
python -m research.relearning.gate                                     # gate (non-zero exit = shut, expected)
```

Python env: `.venv` (3.13). Dataset not in repo — resolved via
`SMARTLEND_CUSTOMER_DATA` or the default Downloads path; raw files in
`data/raw/home_credit/`. GPU: 8 GB RTX 4060 (TabPFN caps at ~5k-row context
locally; `colab/tabpfn_colab_server.ipynb` is the bigger-GPU path).

## Writing style for docs here

Numbers with sources, limitations stated before an examiner finds them,
negative results reported as findings. Historical/superseded docs go to
`docs/archive/` with a line in its README — they are never silently deleted.
